## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
AIwitness 위클리(https://aiwitness.kr/weekly)를 참고한 주 1회 리캡 회차. 데일리 브리핑이 항목 나열이라면, 위클리는 그 주 회차들을 재료로 흐름을 서사로 엮는 판단 메모다.

참고한 형식(7월 5주차 회차 실측):
- 캐치한 두 줄 헤드라인("1점 차이, 80% 인하 — 이번 주 경쟁은 벤치마크가 아니라 가격표에서 벌어졌다")
- 요일별 타임라인(월~일, 사건 한 줄씩)
- '이번 주 이야기' 2-3편 — 개별 항목을 맥락으로 엮은 서사, 모든 주장에 인라인 출처 링크

검토할 것:
- 경로: p/briefing/weekly/<식별자>/ 형태가 자연스럽다. 데일리와 같은 noindex·갤러리 미노출 정책을 따를지, 아카이브(p/briefing/archive/)에 어떻게 섞을지 결정.
- 재료: 그 주 데일리 회차의 수집·선별 데이터(nuc14 ~/jobs/liv-briefing/ 산출물)를 재사용한다. 원문 재수집 없이 compose 만 주간 단위로 한 번 더 돈다.
- 발행 요일: AIwitness 는 화요일. 브리핑 리듬(매일 09:00)에 맞춰 정한다.
- 리브 화자: 데일리보다 서사가 길어지므로 캐릭터 규칙(드물수록 효과가 크다)을 지키면서 판단 메모 어투를 잡는다.

## Implementation Notes

<!-- SECTION:NOTES:BEGIN -->
구현 완료(2026-08-06), AC#6(실제 발행)만 남았다.

착수 전 확인에서 계획의 전제가 하나 틀린 것을 잡았다 — 주간 리캡은 task-91 로 이미 돌고 있었다(일요일 09:20 cron, p/briefing/recap/<날짜>/, 2026-08-02 1건 발행). 그래서 이 태스크는 신규 구축이 아니라 기존 회차의 형식 개편이다. 태스크 설명이 제안한 p/briefing/weekly/ 경로는 폐기했다 — 이미 나간 URL 이 있고 바꿔서 얻을 것이 없다. 발행 요일도 일요일 유지(AIwitness 는 화요일이지만 데일리 리듬에 붙는 자리가 낫다).

설계 판단 셋:
- 헤드라인에 새 필드를 만들지 않았다. 기존 title·description 이 이미 그 역할이라 headline 을 따로 파면 모델이 둘을 어정쩡하게 나눠 쓴다. 템플릿에서 description 을 .dek 로 본문에도 세우고, 프롬프트가 둘이 같은 말을 안 하도록 요구한다.
- 요일 타임라인은 모델을 거치지 않는 결정적 생성이다. 각 회차의 sidebar 한 줄을 그대로 옮긴다. 모델에 맡기면 collect 의 backfill 로 같은 항목이 여러 회차에 반복 등장해 '화요일에도 X, 수요일에도 X' 가 되고, 이미 있는 정보를 지어낼 수 있는 형태로 두 번 싣게 된다. 기존 sources 목록을 이것으로 대체해 중복도 없앴다.
- 근거 링크는 [[날짜#앵커|글자]] 마커로만 쓰게 하고 link_refs() 가 그 주 실제 앵커와 대조해 통과분만 <a> 로 세운다. 없는 조합은 링크를 벗기고 글자만 남긴다.

AC#5 는 '이미 성립' 이 아니었다. recap.sh 와 run.sh 가 락 파일은 달랐지만 전용 클론 $BASE/repo 를 공유하며 둘 다 reset --hard 를 쳐서, 일요일 데일리가 push 재시도로 09:20 을 넘기면 리캡이 진행 중 작업을 밟았다. 공용 락으로 묶으면 한쪽이 다른 쪽 발행을 건너뛰게 만들어 AC 를 정면으로 어긴다. 클론을 repo-recap/ 으로 분리해 공유 상태를 없앴다(디스크 76MB). 클론은 사전 생성해 뒀다.

검증: 실데이터 end-to-end dry-run 을 스크래치 트리에 렌더했다(2026-08-06 기준 7회차). 이야기 3편·근거 링크 14개 전부 대조표 통과·타임라인 7행·em-dash 0·17KB. 아카이브 목록이 의존하는 <title>… · 주간 리캡</title> 정규식도 유지됨을 확인했다. 타임라인 UI 의 브라우저 렌더 검증은 이 머신에 puppeteer 가 없어 못 돌렸다.

AC#6 은 일요일(2026-08-09) 09:20 정기 회차가 검증 창이다. 2026-08-02 회차를 새 형식으로 덮어쓰는 안은 버렸다 — 이미 Slack 으로 공지된 URL 의 내용이 통째로 딴 글이 되고, recap.sh 에 재공지 가드가 없어 Slack 알림이 또 나가며, 얻는 것은 AC 를 사흘 일찍 닫는 것뿐이다.
