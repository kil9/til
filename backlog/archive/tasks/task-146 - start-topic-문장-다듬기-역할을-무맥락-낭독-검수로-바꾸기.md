## Implementation Notes

<!-- SECTION:NOTES:BEGIN -->
무엇을: start-topic SKILL.md 역할 4 를 '무맥락 낭독 검수'로 바꿨다. 아나운서 낭독 기준, 메인 세션이 korean-polish §0 으로 진단한 {방향} 전달, 점검 6항(어순·조사 / 긴 문장·관계절 / 명사형 / 숫자·고유명사 읽기 / 종결 반복 / 기존 스타일 규칙), 문체·1인칭·수치 유지, 사용자가 직접 쓴 문장 {제외}, 보고 '원문 → 수정안 (이유)' 30개 이내. 표와 본문 모두 반론·검증 에이전트와 다른 새 서브에이전트로 띄우고 본문만 넘기게 적었다. 읽기 전용은 공통 머리말이 맡는다.
검증: drafts/ai-point-of-no-return.md 초안 본문으로 새 프롬프트를 Sonnet 서브에이전트에 돌렸다(방향: 목록 1-4 압축, 산문 문단 해당 없음. 필자 문장 2개 제외 지정). 22건이 나왔고 30개 이내, 제외 문장은 건드리지 않았다. 압축 목록에는 서술어·주어 복원 수정안을 냈고("전력. … 증설 및 유지보수." → "전력이 필요하다. 발전소와 송전망을 증설하고 유지보수해야 한다."), 숫자·약어 읽기(GPU, 괄호 '(집단)')와 한 호흡이 긴 결론 문장도 잡았다. 스타일 규칙 위반은 0건으로 보고했다.
보정: 수정안 없이 짚기만 한 항목(읽기 지정, 어조 지적)이 형식 밖으로 섞여서 그런 항목은 끝의 '참고' 아래에 모으라는 한 줄을 보고 지시에 더했다. 초안 자체는 고치지 않았다(대부분 사용자가 직접 쓴 문장이다).
