01Retrieval as Reasoning - LLM Wiki가 RAG보다 나은 이유에 대한 실증 벤치마크

문서를 잘게 잘라 비슷한 조각을 꺼내 붙이는 순간, 조각들 사이의 관계는 사라진다. 여러 문서를 이어야 답이 나오는 멀티홉 질문에서 청크 검색이 무너지는 건 튜닝의 문제가 아니라 구조의 한계다. 그래서 검색을 '조각 꺼내기'가 아니라 '추론'으로 다시 놓고, 원문서를 양방향 링크가 걸린 위키 페이지로 컴파일한 뒤 에이전트가 읽고 링크를 따라가며 되짚게 했다.

  • 도구는 검색·읽기·링크 따라가기 셋으로 표준화했고, Error Book이 위키의 구조·의미 오류를 계속 스스로 고쳐 쓸수록 위키 자체가 나아진다.
  • 멀티홉 QA 세 종류에서 기준 모델 대비 2.0-8.1 F1을 앞섰고, 별도 벤치마크 AuthTrace에서도 정확도 1위였다.
  • ablation이 가장 흥미롭다. 순회를 빼면 −11.7 / −13.8 / −12.2, 위키 구조를 빼면 −6.1 / −7.0 / −6.7, Error Book을 빼면 −3.8 / −4.0 / −3.4로, 순회가 구조보다 두 배쯤 중요하다.
  • 논문과 별개로 굴러가던 Claude Code 기반 위키 구현체는 구조에 오래 공들이고 순회는 지침 한 줄이었음을 뒤늦게 알고, 쓰기 전에 얼마나 읽을지를 다섯 단계로 나눈 읽기 사다리(GROUND Ladder)를 붙였다. 효과 측정은 아직이다.

arxiv.org · 관심사 최상 · 추천 상위 40.7%

til 연관그래프 엔지니어링 — 직선 에이전트에서 그래프 아키텍트까지 이 글은 직선으로 흐르는 에이전트를 그래프로 세우는 이야기였는데, 이번 논문은 그 그래프를 지식 쪽에 두고 순회가 구조보다 중요하다는 숫자를 붙였습니다.

재밌는 건 저 구현체가 논문을 모르고 만들어졌다가, ablation 표를 보고서야 자기가 가장 덜 공들인 칸이 제일 중요한 칸이었다는 걸 알았다는 대목입니다. 「그래프 엔지니어링」에서 관리자님이 정리하신 것과 같은 자리에 걸려 있습니다.

02kubara - 모범 사례 기반으로 Kubernetes 플랫폼을 부트스트랩하는 CLI

Kubernetes 플랫폼을 GitOps 전제로 부트스트랩하고 운영하는 의견 있는(opinionated) CLI다. 플랫폼 스캐폴딩, 환경 구성, 프로덕션 기본값을 Go 단일 바이너리 하나로 묶었고, 멀티 클러스터·멀티 테넌트를 처음부터 대상으로 잡았다.

  • 부트스트랩 기반과 기본 플랫폼 스택을 OCI 카탈로그에서 해석하며, 클러스터별 카탈로그 설정과 커스텀 카탈로그를 지원한다. 확장은 Terraform·Helm 컴포넌트로 한다.
  • 명령은 init·generate·bootstrap·schema·catalog·cluster로 나뉘고, agents 명령으로 AI 코딩 어시스턴트용 AGENTS.md 를 스캐폴딩한다.
  • 매 실행 시 GitHub 새 릴리스를 확인하며 KUBARA_UPDATE_CHECK=0 으로 끌 수 있다. 소스는 Apache 2.0, 문서는 CC BY 4.0 이중 라이선스다.

github.com/kubara-io · 관심사 중 · 추천 상위 46.4%

인기축으로 확정돼 규칙상 들어온 자리입니다. 눈에 걸린 건 agents 명령 하나뿐이라, 플랫폼 CLI가 AGENTS.md 를 기본 산출물로 넣기 시작했다는 정도로 읽었습니다.

03Bending Spoons, Airtable을 12억 8000만 달러에 인수

7월에 상장한 Bending Spoons가 Airtable을 현금 12억 8000만 달러에 인수하기로 합의했다. IPO 이후 첫 인수합병이고, 인수 측이 추산한 Airtable의 기업가치 약 22억 5000만 달러보다도 낮은 가격이다.

  • Airtable은 지금까지 14억 달러 이상을 투자유치했고, 호황기였던 2021년 기업가치는 110억 달러였다. 올해 초 2차 시장 거래는 40억 달러 수준이었다.
  • Bending Spoons는 구조조정을 거친 뒤 수익성 있게 운영하겠다고 밝혔다.
  • 이 회사는 Evernote, WeTransfer, Eventbrite, Vimeo 등을 인수해 왔고, Evernote와 Vimeo는 인수 직후 직원 상당수가 해고됐다는 보도가 있었다.

techcrunch.com · 관심사 중 · 추천 상위 79.3%

110억에서 12억 8000만까지 내려온 숫자보다, 인수자가 추산한 22억 5000만보다도 낮게 팔렸다는 쪽이 더 말이 됩니다. 투자유치 총액 14억 달러도 못 건진 셈입니다.
