01벡터 데이터베이스여, 안녕

turbopuffer는 아주 저렴하면서 적당히 빠른 벡터 검색에서 출발했고, 지금은 전문 검색과 집계까지 처리합니다. 그런데 저장 구조는 여전히 벡터의 ANN 주소를 기준으로 짜여 있어서, v3에서는 문서 저장을 벡터 인덱스에서 떼어 내고 있습니다.

  • v1은 SPANN에서 시작해 SPFresh로 옮겨 간 계층형 클러스터링 인덱스였습니다. 문서와 속성, 역색인이 모두 ClusterId와 LocalId를 합친 ANN 주소를 키로 씁니다.
  • 이 구조로 벡터 1,000억 개를 담은 단일 인덱스에서 1,000 QPS, p99 200ms를 냈습니다. 대신 세 가지 비용이 따랐습니다. 다중 벡터 문서는 내용을 중복 저장해야 하고, 재균형 때 속성·전문 검색 인덱스까지 옮기면서 쓰기가 증폭되고, 처리 블록 크기가 100-200개짜리 클러스터에 묶였습니다.
  • 전문 검색 포스팅을 약 256개 단위 고정 블록으로 바꿨더니 인덱스는 10분의 1로 줄고 쿼리는 최대 20배 빨라졌습니다. v3는 자동화 테스트를 통과했고, 벤치마크로 기존 성능 이상임을 확인한 뒤 운영에 넣을 계획입니다.

02AI 네이티브 회사에서 일한다는 것

03Pi Durable - 중단된 작업을 이어가는 AI 에이전트 하네스

Pi Durable은 오래 실행되는 에이전트 애플리케이션을 만들기 위한 실험적 하네스입니다. 터미널 코딩 에이전트 Pi 1.0과는 별개이고, 핵심은 프로세스가 죽어도 마지막 체크포인트에서 다시 시작하는 것입니다.

  • 실행 단계마다 체크포인트를 남깁니다. 중단된 모델 요청은 다시 보내지만, 도구 호출은 재실행해도 안전하다고 지정한 것만 반복하고 나머지는 중단됐다는 사실을 모델에 알립니다.
  • requestId로 같은 제출을 정확히 한 번만 처리합니다. 대화는 기록의 어느 지점에서든 분기할 수 있고, 대화마다 모델, 도구, 지침, 실행 환경을 따로 둡니다.
  • 테스트를 뺀 소스가 약 15,000줄이라 에이전트가 자기 코드를 통째로 읽을 수 있습니다. 저장소 백엔드는 메모리, SQLite, JSONL을 기본으로 제공하고, 오래된 대화는 백그라운드에서 압축하되 원본 기록은 보존합니다.

05생각을 정리하는 도구로서의 커밋 설명

커밋 설명을 직접 쓰다 보면 변경을 다시 읽고 결정을 재검토하게 됩니다. AI가 코드부터 메시지까지 다 써 주는 지금은 이 과정이 더 필요합니다.

  • 에이전트는 여러 채널에 흩어진 맥락을 모르면 변경 이유를 지어냅니다. 맥락을 충분히 주면 그런 일은 줄지만, 코드가 설명대로 동작하는지 검증하는 일은 여전히 사람 몫입니다.
  • '우리가 …할 때까지 이렇게 처리한다' 같은 1인칭 문장에는 임시 결정을 언제 끝낼지가 담깁니다. 너무 당연해서 어디에도 적지 않은 조건은 AI가 추론해 낼 수 없습니다.
  • 변경의 '왜'를 설명하지 못한다면 이해하지 못한 변경을 배포하는 셈입니다.

06Git 3.0의 SHA-256 기본값 전환은 값비싼 실수다

Git 3.0은 새 저장소의 기본 해시를 SHA-256으로 바꿀 계획입니다. 저는 보안상 얻는 것에 비해 생태계 전환 비용이 너무 크다고 봅니다. 해시는 무결성을 확인해 줄 뿐, 코드를 가져온 출처를 신뢰하게 해 주지는 않습니다.

  • 현실적으로 가능한 공격은 충돌 공격이고, 제2역상 공격은 MD5에서조차 사실상 불가능합니다. 실제로 악성 코드는 해시를 깨서가 아니라 사회공학으로 쓰기 권한을 얻어서 들어옵니다.
  • SHA-1 저장소와 SHA-256 저장소가 갈리면 서브모듈과 Git 라이브러리가 서로 맞춰야 하고, 서명, 커밋 링크, 해시 길이를 가정한 도구도 모두 영향을 받습니다.
  • 대안은 SHA-1을 콘텐츠 식별자로 유지하면서, 따로 계산한 강한 해시를 커밋과 태그 서명에 넣는 방식입니다. 개념 증명은 Chromium의 35GB, 210만 개 파일을 5초에 처리했습니다.

blog.gitbutler.com · 관심사 중 · 추천 상위 50.1%

09Pyxel: 그림·사운드 편집기를 내장한 Python 레트로 게임 엔진

Show HN: Pyxel – A Python retro game engine with built-in art and sound editors

Pyxel은 제가 2018년부터 만들어 온 MIT 라이선스의 Python 레트로 게임 엔진입니다. 픽셀아트, 타일맵, 사운드, 음악 편집기가 들어 있어 그래픽과 소리와 코드를 한 도구에서 만들 수 있고, 엔진 자체는 Rust로 구현했습니다.

  • Windows, macOS, Linux, 웹과 일부 리눅스 기반 레트로 휴대기기에서 돌아갑니다. GitHub에 올린 게임은 URL 하나로 브라우저에서 바로 실행됩니다.
