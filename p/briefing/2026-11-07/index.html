02Discord, Electron을 버리고 RAM 사용량이 적은 새 앱으로 전환

Discord가 데스크톱 앱 전체를 Rust로 옮기면서 Electron을 걷어내고 있습니다. 모바일도 React Native를 빼되 네이티브 UI는 유지하고, Rust로 데스크톱과 모바일 코드를 함께 쓸 계획입니다. CTO가 공개한 Windows 클라이언트는 RAM 290MB였고, 지금 앱은 서버 몇 곳만 들어가도 1GB를 쉽게 넘깁니다.

  • Rust는 2018년부터 써 왔고, 인프라와 음성 기술 상당 부분, 현재 클라이언트 일부가 이미 Rust로 되어 있습니다.
  • 데스크톱 UI에는 GPUI를 씁니다. 전체 전환 시점은 아직 정하지 않았고, 곧 사용자 테스트를 시작하기를 바라고 있습니다.
  • 댓글은 반기는 쪽이 많았지만, 이 과정에서 리눅스 지원이 빠질까 걱정하는 목소리와 Electron을 두둔하는 말투를 흉내 낸 패러디도 섞였습니다.

07로컬 LLM, 권장된 샘플링 대신 temp 0으로 실행해도 되나? ( 한국어 문서 RAG 320문항 재측정)

한국어 문서 RAG 시험을 temp 0으로 돌렸더니 카드 권장값으로 재야 공정하다는 지적을 받았습니다. 그래서 RTX 3090에서 qwen3.8 27B와 Nanbeige4.3 33B를 권장 설정으로 320문항씩 다시 돌렸고, qwen3.8은 생각 켬·끔 모두 짝비교로 차이가 없었습니다. Nanbeige는 66.2%에서 70.6%로 올랐지만, 오른 몫은 출력 한도를 8,192에서 20,480으로 늘린 덕이었습니다.

  • 온도를 올리면 끝없이 생각하다 잘리는 답이 늘어서, 20,480 한도에서 잘린 답이 온도 0에서 약 3개, 0.6에서 10개, 1.0에서 11개였습니다.
  • 같은 29문항을 같은 설정으로 두 번 돌리니 17개, 15개가 나왔고 시드를 고정해도 같은 답이 다시 나오지 않았습니다. 한 번 측정의 1-2%p는 잡음으로 봐야 합니다.
  • Nanbeige 카드가 권하는 262,144 토큰 한도는 3090에서 문항당 7시간이 넘어 현실적으로 못 씁니다. 스크립트와 문항별 판정은 재현 파일로 공개했습니다.
