01AI가 코드를 쓸수록 도메인 주도 설계가 더 중요해지는 이유

AI가 언어와 프레임워크의 구현 세부를 빨리 처리해 줘도, 무엇을 어떤 방식으로 풀어야 하는지 이해하는 일은 여전히 사람 몫입니다. 코드를 빨리 만들수록 잘못 이해한 요구사항도 더 크게, 더 빨리 구현됩니다. 그래서 여러 팀이 오래 유지하는 복잡한 시스템일수록 도메인 모델링이 오히려 더 중요해진다고 봅니다.

  • 도메인 모델은 에이전트가 대신 써 준 문서가 아닙니다. 개발자와 도메인 전문가가 함께 탐색하면서 머릿속에 쌓은 공통 이해입니다. 아무도 읽지 않은 긴 설계 문서는 모델이 되지 못합니다.
  • 에이전트가 큰 기능을 한 번에 만들기 전에 도메인 동작, 경계, 위험, 작은 변경 단위를 짧게라도 함께 정하면 거대한 PR에서 뒤늦게 방향을 다투는 일이 줄어듭니다. 코드 리뷰는 합의한 설계가 제대로 구현됐는지 확인하는 단계여야 하고, 접근 방식을 처음 논의하는 곳이 되어서는 안 됩니다.
  • 코드, 문서, 대화에서 같은 용어를 쓰고 영역 경계를 분명히 해 두면 에이전트도 비슷해 보이는 개념을 잘못 합치지 않습니다. 다만 개인 프로젝트나 단순 CRUD에는 이런 모델링이 다 필요하지는 않습니다.

03Cloudflare, 에이전트 시대의 Git 플랫폼 개발 대회 개최

GitHub는 사람이 코드를 쓰고 브랜치, 커밋, PR로 협업한다는 전제로 만들어졌습니다. 그래서 수백, 수천 개 에이전트가 한 코드베이스에서 동시에 일하는 환경에 맞는 Git 플랫폼을 Workers와 Artifacts 위에서 만들어 달라는 대회를 엽니다. 최소 조건은 여러 에이전트가 동시에 변경 작업을 하는 것이고, GitHub에 에이전트를 덧붙이는 수준을 넘어서길 바랍니다.

  • Artifacts는 수백만 저장소까지 확장되는 Git 호환 버전 관리 파일시스템입니다. 에이전트, 세션, 작업마다 저장소를 포크하고, 푸시 이벤트를 구독해 리뷰 에이전트를 띄우는 흐름까지 코드로 짤 수 있습니다.
  • 마감은 2026년 10월 14일입니다. 5-10분짜리 시연 영상, 허용적 라이선스로 공개한 소스, 실행 방법을 내야 합니다. 1위에는 Cloudflare 크레딧 2만 5,000달러가 걸렸고, Artifacts 과금은 10월 15일부터 시작합니다.
  • 댓글에서는 참가 자격이 미국과 캐나다 거주자로 묶여 있어 한국 거주자는 낼 수 없다는 지적, 상금이 아쉽다는 반응이 나왔습니다.

05AI 네이티브 SDLC - 개발 전 과정을 에이전트에 맞게 재설계하기

에이전트 덕에 구현이 몇 시간으로 줄어도 계획, 검토, 보안 승인, 배포가 예전 속도라면 병목은 앞뒤 단계로 옮겨 갈 뿐입니다. 그래서 역할별로 차례차례 넘기는 선형 인계를 버리자고 제안합니다. 대신 각 단계가 Git에 커밋한 산출물이 다음 단계를 시작시키는 순환 구조로 바꾸는 겁니다.

  • 산출물은 intent.md, spec.md, plan.md, 코드와 테스트, PR 리뷰 결과, 장애 기록 순서로 이어집니다. 커밋 기록이 그대로 누가 요청하고 누가 승인했는지 보여 주는 감사 추적이 됩니다.
  • 구현 전에는 Claude Code 계획 모드로 plan.md 를 만들어 승인을 받습니다. 다른 엔지니어가 대화 기록 없이도 구현할 수 있을 만큼 변경 파일, 순서, 위험, 버린 대안, 검증용 테스트를 적습니다. 구현 중에 판단이 바뀌면 plan.md 도 함께 고칩니다.
  • 기계적인 검증은 테스트, 평가 스위트, 스킬, 훅, 샌드박스에 맡기고 사람은 요구사항 승인, 위험 판단, 프로덕션 배포에 집중합니다. 운영 지표가 허용 범위를 벗어나면 감시 장치가 에이전트를 불러 새 intent.md 를 쓰게 하고, 같은 경로가 다시 돕니다.
