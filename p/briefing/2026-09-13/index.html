06Google 검색, 목적지 주소를 바로 읽을 수 없는 리디렉션 링크 확대

Google 검색 결과의 링크가 실제 주소 대신 google.com/goto?url=... 형태로 바뀌고 있습니다. 예전 /url?q= 와 달리 url 값은 Google 고유 인코딩이라서, 링크 문자열만으로는 목적지를 복원할 수 없습니다.

  • 목적지는 goto에 요청을 보내되 리디렉션을 따라가지 않고 Location 헤더만 읽으면 알 수 있습니다. 대신 결과마다 요청이 하나씩 늘어서 대량 수집이 느려지고 Google 눈에도 잘 띕니다.
  • 도메인과 파비콘 표시에 쓰는 목적지 사본은 페이지에 남아 있습니다. 2026년 8월 말부터 로그아웃·비공개 세션에서는 사실상 모든 링크가 goto였지만, 아직 실험일 수도 있습니다.
  • &num=100 제거, BotGuard·SearchGuard 강화에 이어 단순한 검색 결과 수집의 비용을 올리는 흐름으로 봅니다.

08Switchyard - OpenAI/Anthropic API 그대로 모델을 바꿔 쓰는 LLM 라우터

Switchyard는 모든 요청을 비싼 모델에 맡기는 대신, 그 작업을 처리할 수 있는 더 저렴한 모델을 고르려고 만들었습니다. OpenAI Chat Completions·Responses와 Anthropic Messages 형식을 지원하니, 기존 클라이언트는 연결 주소만 프록시로 바꾸면 요청마다 다른 모델을 쓸 수 있습니다.

  • 요청을 먼저 분류하거나, 저렴한 모델의 답을 평가한 뒤 강한 모델에 다시 맡기거나, 상위·하위 에이전트에 서로 다른 모델을 배정하는 전략 중에서 고를 수 있습니다.
  • Stage Router는 도구 실행 이력의 오류와 반복 시도를 보고, 탐색과 오류 복구에는 강한 모델을, 정형적인 작업에는 저렴한 모델을 붙입니다. 기본적으로는 LLM을 추가로 호출하지 않고 판단합니다.
