01실전파 컴퓨터 과학자를 위한 도서 목록

코드 작성 관행을 다루는 흔한 추천서는 뺐습니다. 언어, 운영체제, 네트워크, 알고리듬, 계산 이론을 깊이 익히는 책만 2025년판으로 추렸습니다. 입문은 C/C++와 Rust에서 시작하는데, C를 직접 쓸 일이 없더라도 주요 운영체제의 네이티브 API가 C로 표현되기 때문입니다.

  • 실전 단계에는 Knuth TAOCP 1권과 4B권(제3판), Hacker's Delight 제2판, APUE 제3판처럼 판본까지 지정했고, Dijkstra의 A Discipline of Programming은 쪽마다 가장 아름다운 책으로 꼽았습니다.
  • Josuttis의 C++ Move Semantics는 이동 의미론 하나 설명하는 데 200쪽이 필요하다는 점에서, 어느 Rust 책보다 Rust가 왜 필요한지 잘 납득시킵니다.
  • 머신러닝, 양자 컴퓨팅, 가속기, 정보보안 책은 일부러 뺐고 조합론, 확률/통계, 선형대수는 꼭 익히라고 권합니다.

04Protomaps: 지도 타일 셀프 호스팅이 저렴하고 쉬워졌다

여행 계획용 지도 도구를 만들다가 Protomaps를 검토했습니다. PMTiles는 지도 타일을 파일 하나로 묶고 HTTP Range 요청으로 필요한 부분만 가져오므로, Range 캐싱을 지원하는 CDN이면 스토리지에 파일을 올리는 것으로 배포가 끝납니다. Bunny.net에서 139GB 세계 지도를 다섯 지역에 복제해도 스토리지는 월 5달러 정도입니다.

  • 지도 로딩 한 번에 5MB를 쓴다고 보면 1,000회당 약 0.05달러로 Mapbox보다 100배 쌀 수 있지만, Mapbox는 방문당 정액이라 실제 비교는 이용 방식에 따라 달라집니다.
  • Optimize for large object delivery를 켜야 Range 요청이 캐시되고, 한 요청에서 10MB를 넘기면 속도를 10kB/s로 묶어 파일 통째 다운로드에 따른 요금 폭탄을 막습니다.

05Woz는 컴퓨터를 만들기도 전에 어떻게 Apple 1 BASIC을 작성했을까?

  • BASIC 자체는 Apple 1에서 처음 돌렸지만, 수식 평가용 스택 머신만은 ALGOL로 따로 짜서 컴퓨터에서 시험했고 HP 계산기로 스택식 사고에 익숙해졌습니다.
  • 인터프리터를 편집기, 토큰화기, 실행 루프, 수식 평가기, 명령별 처리 함수로 나누면 하나하나는 몇 줄에서 100개 명령어 정도라 종이에서도 다룰 만했습니다.
