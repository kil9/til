01wsrv.nl - 무료 오픈소스 이미지 CDN

원본 이미지 URL만 넘겨주면 리사이즈·크롭·포맷 변환·압축을 실시간으로 처리하고 CDN에 캐싱해 돌려줍니다. 가입도 API Key도 필요 없이 URL 파라미터만으로 씁니다. 서버 코드 전체가 BSD 3-Clause로 공개돼 있어 Docker로 직접 호스팅할 수도 있습니다.

  • w·h·dpr로 크기와 해상도를 조절하고 fit과 위치 지정, attention·entropy 기반 스마트 크롭까지 지원하며 출력은 JPEG·PNG·WebP·GIF·TIFF·JXL로 뽑을 수 있습니다.
  • 내부는 nginx와 libvips이고 결과는 Cloudflare CDN의 300여 개 데이터센터에서 전달되며, 공개 인스턴스 기준 시간당 약 2천만 장을 처리하고 월간 아웃바운드는 약 1PB입니다.
  • 무료인 만큼 제한이 있습니다. 캐시되지 않은 요청은 IP당 10분에 2,500개, 일부 오리진 도메인은 필터링되고, 서버 캐시가 보통 7일에서 최대 31일 유지돼 원본을 교체해도 즉시 반영되지 않습니다.

02아무도 부탁하지 않은 것을 만들어라

직업 세계는 아이디어에 대상 독자와 성과와 지표를 먼저 요구하도록 훈련시킵니다. 하지만 어떤 작업은 무엇을 위한 것인지 설명할 수 있기 전에 먼저 존재해야 합니다. 유용성이 늦게 도착하도록 보호하는 공간을 하나쯤은 남겨 두자는 이야기입니다.

  • 제약 자체가 나쁘진 않았습니다. 클라이언트 작업은 완성하는 법을, 마케팅은 아이디어가 사람에게 닿는지를, 제품 일은 의도와 행동이 다르다는 것을 가르쳤습니다. 문제는 이 사고가 사적인 호기심까지 잠식할 때입니다.
  • 의뢰받지 않았다는 것이 가볍다는 뜻은 아닙니다. 외부 승인자가 없으니 주제와 기준을 전부 스스로 정해야 하고, 그래서 주의력·순서 구성·완성 능력·취향·정체성이 훈련됩니다.
  • 인터넷과 AI가 아이디어에서 결과물까지의 거리를 거의 없앤 대신, 첫날부터 누구를 위한 것인지 수익화가 되는지를 묻는 습관도 같이 키웠습니다. 30일째에 유용한 질문을 첫날에 하면 따라갈 이유 자체가 죽습니다.

04Edge Vision AI - AI를 현실 세계로 가져오는 기술

현업에서 Vision AI와 MLOps 플랫폼을 만들며 배운 Edge Vision AI의 구조를 정리했습니다. 영상은 크고 계속 발생하니 전부 클라우드로 보내면 비용과 지연이 문제이고, 정작 필요한 것은 영상이 아니라 거기서 뽑은 정보인 경우가 많습니다. 그래서 현장에서 바로 추론하는 쪽이 잘 맞습니다.

05Yap - LLM이 코드에 남기는 ‘주석 슬롭’

LLM이 코드를 산더미로 만들면 누군가는 결국 그것을 읽어야 합니다. AI가 만든 코드에는 말은 많은데 이해에는 도움이 안 되는 특정 형태의 슬롭이 있고, 저는 그것을 yap이라고 부르기로 했습니다. 이해시키려는 말이 아니라 생각을 이어가려는 독백이 코드에 남긴 잔여물입니다.

  • 단순한 타입 위의 30줄짜리 주석, 함수 위에 몰아넣은 200줄짜리 설명, 무엇을 설명하는지 모를 파일 상단의 50줄이 대표적입니다.
  • 주석에는 틀렸는지 알려주는 컴파일러가 없습니다. 시그니처가 바뀌면 코드는 고쳐야 돌지만 주석은 틀린 채로 남아도 프로그램이 아무렇지 않게 돕니다.
  • 첫 번째 로봇의 코드를 두 번째 로봇에게 검토시키자는 주장에는 회의적입니다. 두 번째가 더 나은 취향을 가졌다고 믿을 근거가 없으니 사람이 남아야 하고, 그렇다면 반복되는 지적을 한 단어로 줄일 표현이 필요합니다.
