01직장인으로서 부를 쌓는 방법

직장 생활도 부를 쌓는 동력이 될 수 있습니다. 다만 높은 소득이 곧 부는 아닙니다. 일의 가치를 키우는 것과 늘어난 소득의 상당 부분을 자산으로 바꾸는 것, 두 가지를 함께 해야 합니다.

  • 성적은 첫 기회를 여는 데까지 도움이 됩니다. 그 뒤의 경력은 문제 해결 능력과 검증 가능한 성과가 결정합니다.
  • 지식을 혼자 쥐고 있으면 대체 불가능해 보여도 오히려 승진이 막힙니다. 시스템을 만들고 후임자를 키워 둬야 더 큰 역할을 맡을 수 있습니다.
  • 생활 수준이 지나치게 오르는 것을 막고 고금리 부채부터 줄입니다. 저축과 투자는 자동화하고 소득이 늘 때 투자금도 같이 늘립니다. 목표는 다음 급여에 기대는 정도를 줄이는 것입니다.

05jevgrep - 코드의 동작을 질문해 관련 파일을 찾는 코딩 에이전트용 CLI

낯선 코드베이스에서 코딩 에이전트가 필요한 파일을 찾도록 만든 검색 CLI입니다. '인증은 어디서 검사해?'처럼 동작을 물으면 관련 파일과 원문 발췌, 줄 번호를 돌려줍니다.

  • Jev가 폴더, 파일, 함수 순으로 관련성을 판정하며 저장소 계층을 내려갑니다. Python, TypeScript/JavaScript, Go, Rust의 선언 구문을 분석합니다.
  • 검색 대상 소스는 외부 공급자로 전송됩니다. 기본 필터가 자격 증명 파일 등을 빼지만 모두 걸러진다는 보장은 없으니, jg files로 범위를 먼저 확인하는 편이 좋습니다.
  • 자체 평가에서 Python SWE-bench 과제 10개 중 기존 방식과 같은 8개를 풀면서 Jev를 포함한 총비용을 25.8% 줄였습니다.

06MCP Gateway - 기존 API를 MCP 도구로 통합하는 Uber의 플랫폼 설계

흩어져 있던 MCP 연동을 MCP Gateway 하나로 묶었습니다. 지금 서버 800개 이상, 도구 5,000개 이상을 운영하고 있고, 기존 백엔드는 손대지 않았습니다.

  • MCP Registry가 제어 평면, Proxy Gateway가 데이터 평면입니다. 게이트웨이가 MCP 요청을 HTTP, gRPC, TChannel 호출로 바꿔 백엔드에 넘깁니다.
  • AutoCrawler가 IDL과 하트비트로 도구를 찾아내고 LLM으로 설명을 만들지만, 기본값은 비활성입니다. 소유 팀이 검토하고 켜야 하며, 발견이 곧 노출은 아니라는 원칙입니다.
  • 도구 단위 인가와 민감정보 제거를 게이트웨이에서 공통으로 적용하고, 도구 설명이 바뀔 때도 소유자 승인과 롤백을 거칩니다.
