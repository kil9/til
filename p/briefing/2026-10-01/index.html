01스태프 엔지니어를 위한 일감 발굴 가이드

플랫폼 팀에는 로드맵을 건네줄 제품 관리자도, 따라갈 매출 지표도 없습니다. 그래서 다음에 무엇을 만들지는 스태프 엔지니어가 시스템, 사용자, 조직, 업계에서 오는 신호를 읽고 직접 정해야 합니다. 일감이 모자란 경우는 드뭅니다. 어려운 것은 이 일을 다른 후보보다 먼저 해야 하는 이유를 설명하는 일입니다.

  • 장애, 비용, 운영 잡무는 개선할 곳을 알려 주지만 가장 시끄럽고 최근에 터진 문제가 가장 큰 기회라는 뜻은 아닙니다. 비용은 손익계산서와 벤더 계약까지 올라가서 보십시오.
  • 사용자에게 원하는 기능을 묻지 말고 최근 작업을 순서대로 들으십시오. 이미 쓰고 있는 우회책과 원래 용도 밖의 활용은 사용자가 대신 만든 프로토타입입니다.
  • 마이그레이션에서 끝까지 남은 팀은 새 플랫폼이 평균적인 사용자만 보고 놓친 요구를 드러냅니다. 반면 관리자가 반복해서 꺼내는 이야기는 가장 약한 신호입니다.

02cf - Cloudflare 전체 API를 다루는 에이전트용 CLI

cf 공개 베타를 냈습니다. Wrangler로는 약 280개 작업만 다룰 수 있었는데, 이제 CLI 하나로 3,000개가 넘는 Cloudflare API 작업을 처리합니다. 지난주 Wrangler 사용량의 48%가 에이전트였기 때문에 cf는 처음부터 에이전트를 기준으로 설계했습니다.

  • 명령은 OpenAPI 스키마에서 자동으로 생성합니다. 출력은 기본이 JSON이고, cf cli search로 필요한 명령을 자연어로 찾을 수 있어 시간과 토큰을 아낍니다.
  • 설정은 cloudflare.config.ts에 TypeScript로 씁니다. 공통 설정에서 환경별 구성을 코드로 만들 수 있어, 사내의 5,000줄 넘는 설정이 40% 줄었습니다.
  • 개발 도구는 Vite를 기본으로 씁니다. 기존 Worker는 cf migrate로 옮길 수 있고, Wrangler는 마지막 메이저 버전 이후 18개월간 유지보수합니다.

03LatticeDB - 그래프, 벡터, 전문 검색을 한 파일에 담는 임베디드 DB

관계 탐색, 의미가 비슷한 문서 검색, 키워드 검색을 로컬 DB 파일 하나에서 처리하는 오픈소스 데이터베이스입니다. 서버나 별도 설정 없이 애플리케이션 안에서 돌아가고, Cypher 기반 질의 하나로 그래프와 HNSW 벡터 검색, BM25 전문 검색을 함께 씁니다.

  • Graph RAG나 에이전트 메모리를 만들 때 검색 엔진 여러 개를 따로 운영하지 않고 파일 하나로 끝낼 수 있습니다.
  • WAL 기반 복구, 실행 중 백업, 특정 시점 복구를 지원합니다. 대신 한 머신에서 한 프로세스가 파일을 관리하는 구조라 분산 DB와는 용도가 다릅니다.
  • Zig로 구현했고 Python, TypeScript, Go, Java 바인딩을 제공합니다. 벤치마크는 재현 명령과 함께 공개했습니다.

04그렇다, 이제 AI가 없는 것도 기능이다

LibreOffice는 AI를 거부하지 않습니다. 다만 사용자 통제와 프로젝트 원칙을 모두 지키는 통합 방식이 나오기 전까지는 기본 설치에 AI를 넣지 않겠습니다. 문서는 사용자의 것이고, 그 문서를 승인 없이 컴퓨터 밖으로 보내는 기본값은 선택권이라고 할 수 없습니다.

  • 기본 탑재 조건은 여섯 가지입니다. 추론 위치를 사용자가 고를 것, 승인 없이 문서를 전송하지 않을 것, 텔레메트리가 없을 것, 단일 공급업체에 묶이지 않을 것, ODF를 유지할 것, 완전히 선택적일 것.
  • AI가 필요한 사용자는 Ollama나 LM Studio 같은 로컬 모델에 연결하는 서드파티 확장을 쓰면 됩니다. 쓰지 않는 사용자의 화면에는 아무것도 나타나지 않습니다.
  • 구독을 파는 기업에게 AI는 가격 인상의 명분이 되지만, 비영리 조직인 저희는 분기 실적에 쫓기지 않고 쓸모를 판단할 수 있습니다.

05Jeeves - 판단 전에 추론하는 Jev 방식의 의사결정 모델

Jev 방식 모델은 선택지별 확률을 곧바로 내놓지만 복잡한 판단에서는 정확도가 모자랍니다. Jeeves는 Qwen3.5-9B 위에서 답을 고르기 전에 먼저 추론하도록 학습했고, JevBench 공개 231문항에서 93.5%를 기록해 Jev의 86.6%를 앞섰습니다.

  • 확신이 높으면 추론을 건너뜁니다. H100 기준으로 추론을 끄면 약 0.3초, 전체 추론은 중앙값 3.3초이고 p90은 17.1초입니다.
  • LoRA와 포인터 헤드로 선택지를 직접 채점하고, 온도 스케일링으로 확률을 보정합니다. 지식 질문(MMLU)에서는 여전히 Jev가 앞섭니다.
  • 9B 가중치, 확산 기반 초안 모델, 학습 코드와 데이터를 모두 공개해 직접 다시 학습할 수 있습니다.

github.com/PostHog · 관심사 최상 · 추천 상위 45.3%

06OpenAI Dots - 상시 작동하는 AI 에이전트 공개

GPT-6 Astra 기반의 상시 작동 에이전트 Dots를 공개합니다. dot은 자체 클라우드 컴퓨터에서 여러 프로젝트를 동시에 진행하고, 피드백을 받으면서 사용자의 선호와 업무 기준을 익힙니다.

  • 고객 피드백을 코드 수정과 PR로 만들고, 새 데이터로 분석을 다시 돌리고, 빠뜨린 청구서를 준비해 승인을 받은 뒤 발송합니다. ChatGPT, Slack, Teams 어디서 이야기해도 맥락이 이어집니다.
  • Custom Rules로 행동마다 허용, 승인 필요, 차단을 정합니다. 스스로 할 일을 찾는 선제적 조사는 읽기 전용으로 제한됩니다.
  • 조직의 특정 업무를 맡는 전문 Dots는 기업 파일럿으로 먼저 시작하고, Microsoft Agent 365와 통합하고 있습니다.

07Show GN: herdr web ui - 폰이나 브라우저에서 herdr 사용하는 플러그인

  • 채팅 화면과 터미널 화면이 같은 pane을 봅니다. 승인이나 질문은 채팅에서 바로 답하고, TUI가 필요할 때만 터미널로 넘어가면 됩니다.

  • 앱으로 설치해 푸시를 받으려면 HTTPS가 필요해서 저는 tailscale serve로 씁니다. 아직 베타라 버그가 많습니다.

08OpenAI, Jev와 경쟁할 Luna 기반 Decision API 공개

OpenAI가 DevDay에서 소형 모델 Luna 기반의 Decision API를 공개했습니다. 질문, 답변 후보, 맥락을 넣으면 미리 정한 후보마다 신뢰도 점수를 돌려줍니다. 응답 시간은 150ms로, 일반 GPT-6 Luna의 1.6초보다 약 10배 빠릅니다.

  • 주요 용도는 콘텐츠 분류, 요청 라우팅, 에이전트의 다음 행동 선택입니다. 분류 항목이 바뀌어도 재학습 없이 프롬프트로 새 후보를 지정할 수 있습니다.
  • Moderation API도 범주별 점수를 주지만, 그쪽은 OpenAI가 범주를 정합니다. 여기서는 개발자가 정합니다.
  • 9월 29일 기준 제한적 프리뷰입니다. 호출당 가격, 후보 수 제한, 자체 데이터로 조정할 수 있는지는 아직 공개되지 않았습니다.

10'MCP는 안 쓴다'던 Pi, MCP와 Codemode를 말하다

You said no MCP

Pi를 만드는 earendil이 'MCP는 안 쓴다'는 말에 대한 글을 올렸습니다. 원문 본문은 들어오지 않았고 제목과 댓글만 재료입니다. 댓글로 미루어 보면 Pi 최신 릴리스에 들어간 MCP와 Codemode를 다루는 글로 보입니다.

  • 한 댓글은 MCP라는 말이 계속 나오는데 MCP가 무엇인지는 한 줄도 설명하지 않는다고 지적합니다.
  • 다른 댓글은 MCP가 최적은 아니어도 USB-C처럼 호환성으로 이긴 표준이고, 최적이라는 방식 일곱 개보다 넓은 생태계 하나가 낫다고 반박합니다.
