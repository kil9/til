011980년대부터 현재까지, UI 디자인 가이드 69종 모음

1980년 Lisa 부터 지금의 Apple·Material·GNOME 공식 사이트까지, UI 스타일 가이드 69종을 회사와 플랫폼별로 모았습니다. Amiga, NeXTSTEP, Newton, Palm OS 같은 지나간 플랫폼도 넣었고, CDE·OPEN LOOK·SGI 같은 UNIX 데스크톱 문서와 Java Swing 지침도 함께 넣었습니다.

  • 자료는 PDF, 웹 미러, Internet Archive, Wayback 보관본으로 제공하고, 초안과 개정판이 있으면 같이 실었습니다. 전체를 ZIP 하나로 받을 수도 있습니다.
  • 웹 미러는 이미지 픽셀 표현, 링크된 이미지의 본문 삽입, YouTube 삽입 정도만 가볍게 손봐 읽기 편하게 했습니다.

02리만 가설이란 무엇인가? 시각적으로 이해하기

리만 가설은 결국 어떤 수까지 소수가 몇 개인지 셀 때 가우스의 추정이 얼마나 빗나갈 수 있느냐에 관한 명제입니다. 소수 계단 그래프에 제타 함수 영점들이 만드는 파동을 하나씩 더해 가며, 그 오차가 왜 제곱근 규모로 묶이는지 그림으로 보여 드립니다.

  • 1조까지 소수는 37,607,912,018개이고 가우스 추정과의 차이는 38,263개입니다. 리만 가설이 허용하는 상한은 약 110만 개라 아직 한참 여유가 있습니다.
  • 영점이 모두 실수부 ½ 직선 위에 있으면 1조에서 파동이 약 100만 규모지만, 실수부 ¾ 인 영점이 하나라도 있으면 같은 지점에서 약 10억 규모로 1,000배 커집니다.
  • 2026년 11월 Levent Alpöge 가 Claude 와 함께 쓴 증명이 Lean 형식으로 공개됐고, Lean FRO 와 Mathlib Initiative 가 진술 일치와 논증 성립을 확인했습니다. 다만 다음 소수를 바로 찾거나 RSA 를 깨는 방법을 주지는 않습니다.

03AI 덕분에 셀프 호스팅이 다시 즐거워졌다

04Google, AI 에이전트의 Workspace 접근에 자사 MCP 의무화… 공개 Gmail MCP로는 메일 발송 불가

Google 이 11월 24일 Workspace MCP 서버 8개를 정식 출시하면서 API 약관에 Workspace AI Tools Addendum 을 붙였습니다. 2027년 2월 1일부터 AI 에이전트는 공식 MCP 서버나 Workspace CLI 로만 Workspace 데이터에 접근해야 하고, REST 를 직접 부르면 유료 프로젝트여도 Standard 할당량에 묶이면서 약관 위반이 됩니다.

  • 공개 Gmail MCP 는 검색, 읽기, 초안 생성까지만 됩니다. 발송, 답장, 전달, 초안 수정은 파트너 전용이고, Anthropic 의 Claude 용 커넥터는 발송과 Drive 이동을 지원한다고 안내합니다.
  • Workspace 데이터는 사용자가 승인한 진행 중 작업에만 쓸 수 있고, 거기서 만든 임베딩이나 메모리 인덱스는 30일 보존 제한을 받을 수 있으며 학습·증류에는 쓸 수 없습니다.
  • 에이전트 여부는 OAuth 클라이언트의 'AI-powered agent' 체크박스로 스스로 신고하고, 11월 11일부터 MCP 서버는 표시 없는 클라이언트를 거부합니다. AI 를 쓰지 않는 백업이나 동기화 스크립트는 별도 OAuth 클라이언트로 기존대로 돌릴 수 있습니다.

05OpenAI가 비용 통제에 나섰을까? - GPT-6.2의 추론 토큰 감소

같은 과제를 두 모델에 맡겨 겨루게 하는 Agent Duel 데이터를 보니, GPT-6.2 Astra 와 Sol 은 전작보다 작업당 출력 토큰과 추론 토큰을 눈에 띄게 덜 씁니다. Astra 6 과 Sol 6.1 은 상대 모델과 비슷하게 추론했는데, 6.2 의 두 모델은 상대보다 유난히 적게 추론하는 이상치로 바뀌었습니다.

  • 감소는 통계적으로 유의합니다. 출력 토큰은 Sol p=0.0055, Astra p=0.022, 추론 토큰은 Sol p=0.00013, Astra p=0.0064 입니다.
  • 토큰 수만 보지 않고 상대 대비 지출 비율과 대결 결과로 매긴 Elo 를 한 차트에 놓아 비교했습니다.
  • 비용 절감 쪽으로 조정됐을 가능성은 보이지만, 토큰과 API 지출만으로 OpenAI 의 실제 운영비나 조정 이유까지 알 수는 없습니다. HN 에서는 '에이전트 개발은 이제 키우기보다 가지치기'라는 정원 비유가 이어졌습니다.

06Show GN: 틈 - 배포한 사이트를 밖에서 열어 보는 노출 점검 (Supabase 공개 테이블, /.env, 번들 속 키)

배포한 사이트를 밖에서 열어 보고 노출된 키, 열린 /.env, 익명으로 읽히는 Supabase 테이블을 찾아 주는 '틈'을 혼자 만들었습니다. 바이브 코딩한 서비스에서 RLS 를 안 켜 테이블이 통째로 열려 있거나 번들에 service_role 키가 들어간 사례가 계속 나와서입니다.

  • 번들 속 키 패턴(service_role JWT, sk-, AKIA, sk_live_), 보안 헤더·CORS, /.env·/.git/HEAD·소스맵, Supabase 익명 읽기와 Firebase RTDB 공개 여부, Next.js CVE-2025-29927 해당 여부, lockfile 의 OSV.dev 조회와 Shai-Hulud 목록 대조를 봅니다.
