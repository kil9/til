03VM 한 대에서 웹 서버 1,500만 개 실행하기: smoltcp, DPDK, AF_XDP

RAM 10GB, CPU 1코어짜리 VM에서 OK만 돌려주는 웹 서버 1,500만 개를 띄워 봤습니다. 포트는 AnyIP로 IPv6 /64를 통째로 받아 해결했지만, 진짜 병목은 프로세스와 커널 소켓의 메모리였습니다.

  • 서버마다 프로세스를 쓰면 20TB가 필요해서, 런타임 하나에 게스트를 모두 올리고 게스트 상태를 16바이트까지 줄였습니다.
  • 그래도 Linux 소켓은 아무 일도 안 해도 약 3,300바이트를 씁니다. LLM이 유휴 연결은 0바이트라고 답한 걸 그대로 믿은 게 계산이 틀어진 시작이었습니다.

05nginx2root - nginx 원격 코드 실행 취약점 5개와 Linux 커널 권한 상승 취약점

nginx에서 인증 없이 원격 코드 실행이 되는 취약점 5개를 찾았고, Linux SCTP 커널 취약점과 이어 붙여 호스트 root와 Docker 탈출까지 확인했습니다. 가장 넓게 걸리는 CVE-2026-123007은 HTTP/2를 켠 1.9.5부터 1.31.8까지 모든 공식 릴리스에 들어 있습니다.

  • 5개는 서로 독립적이고 각각 다른 설정에서 터집니다. HTTP/2를 끄면 그중 2개만 막히고, mirror만 꺼서는 DNS 리졸버 쪽 경로를 막는다고 장담할 수 없습니다.
  • 배포판이 보안 수정을 백포트하므로 nginx -v 출력으로는 판단할 수 없습니다. 전체 패키지 버전과 보안 공지를 대조하고, 업데이트 뒤에는 리로드가 아니라 재시작으로 바이너리를 바꿔야 합니다.
  • Lobste.rs에서는 패치가 나오기 전에 이만큼 공개한 이유를 묻는 반응과, 업체 홍보 아니냐는 의심이 함께 나왔습니다.
