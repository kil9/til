01Herdr - 터미널과 코딩 에이전트를 한곳에서 관리하는 네이티브 앱

터미널과 코딩 에이전트를 작업 공간·탭·분할 패널로 한 창에 모으는 데스크톱 앱을 냈습니다. 실행은 herdr-core 가 맡고 창은 배치만 하기 때문에, 창을 닫거나 앱을 업데이트해도 터미널은 계속 돕니다. 기존 Herdr TUI 와는 별도 프로그램이라 실행 중인 에이전트를 공유하지 않습니다.

  • 에이전트 사이드바는 여러 공간의 에이전트와 하위 작업자를 한 목록으로 모아 Working·Blocked·Done·Idle 로 표시합니다. 이 상태 구분은 공개 프로토콜 OSC 7501 을 지원하는 에이전트에만 적용됩니다.
  • SSH 머신을 추가하면 터미널이 원격 머신에서 돌고, 레이아웃은 각 머신의 코어가 보관합니다. 그래서 노트북이 절전에 들어가도 원격 작업은 이어집니다.
  • 레이아웃과 JavaScript 모드로 패널·메뉴·단축키를 바꿀 수 있습니다. 다만 모드는 샌드박스가 아니라 신뢰 코드로 실행되고, 릴리스판의 사용량 텔레메트리는 기본으로 켜져 있습니다.

02미니멀 CSS 프레임워크 Pico CSS, 유지보수 종료

Pico CSS 는 v2.1.1 을 마지막으로 유지보수를 끝냅니다. 10월 4일에 저장소를 아카이브했습니다. AI 가 필요한 CSS 만 담은 가볍고 접근성 있는 HTML 을 만들어 주는 지금은 이런 최소 프레임워크가 예전만큼 필요하지 않다고 판단했습니다.

  • 계속 이어 가려면 Sass 를 순수 CSS 로 바꾸고 OKLCH·캐스케이드 레이어·Popover·앵커 포지셔닝을 기반으로 다시 짜야 합니다. 그렇게 나온 결과는 다른 프로젝트라서 하지 않기로 했습니다.
  • npm 패키지·jsDelivr CDN·picocss.com 은 오래 유지합니다. MIT 라이선스라 포크는 자유롭지만 Pico CSS 라는 이름과 로고는 쓰지 말아 달라고 했습니다.
  • HN 댓글은 종료 이유보다 OKLCH 를 두고 갈렸습니다. 최신 기능을 따라가야만 하느냐는 불만에, 기준 색에서 색조를 만들기 쉬운 더 나은 색 체계라는 반박이 붙었습니다.

04tinyworldformer - Raspberry Pi Pico 2 W에서 게임을 생성하는 초소형 월드 모델

작은 신경망 두 개로 Raspberry Pi Pico 2 W 위에서 게임을 만들고 직접 플레이하게 했습니다. 월드 모델은 현재 화면과 행동을 받아 다음 화면과 보상을 내고, 행동 모델은 그렇게 생성된 화면만 보고 다음 행동을 고릅니다. 칩 위에서는 어느 쪽도 실제 게임 엔진을 쓰지 않습니다.

  • 월드 모델은 트랜스포머 블록 하나를 같은 가중치로 1-4회 반복하는 루프형 구조에 int8 양자화를 써서 게임별 파라미터가 2만 6,000-13만 1,000개입니다. 가장 큰 Pac-Man 도 학습기와 디스플레이 드라이버까지 합쳐 플래시 600KB, RAM 460KB 에 들어갑니다.
  • 프레임 완전 일치율은 Flappy Bird 100%, Breakout 99.99% 이지만 Doom-lite 는 83.6%, Pac-Man 은 86.4% 입니다. 반복 횟수를 늘린다고 늘 나아지지도 않아서, Pac-Man 은 2회일 때 가장 높았습니다.
  • HN 댓글에서 밝혔듯이, 보드에서 학습한 행동 에이전트는 월드 모델의 오류를 파고들었습니다. Breakout 에서 모서리를 맞히면 블록이 더 많이 사라졌고, Doom-lite 에서는 아주 먼 거리에서 쏴도 적이 쓰러졌습니다.

05Show GN: Claude 기다리는 동안 보는 Claude Code 애니메이션 패널 모음 (어항·달·모닥불 등 13종)

Claude Code 에 일을 맡겨 두고 'Thinking…' 타이머만 보는 시간이 생각보다 길어서, 모드(mod) 기능을 공부하는 김에 채팅 옆에 띄워 두는 애니메이션 패널을 만들었습니다. 패널마다 Claude 가 쉴 때와 일할 때 장면이 달라집니다.

  • 패널 11개(야간열차, 모닥불, 달, 어항 등)와 프롬프트 위에 붙는 띠 2개(컨텍스트·사용량·비용 한 줄, Haiku 선택 시 경고)가 있습니다. 모드 하나는 plugin.json 과 hooks/register.tsx 로 이뤄진 플러그인 하나입니다.
  • 턴 시작·끝과 도구 호출을 받아 작은 상태만 들고 있다가 상태가 바뀔 때만 다시 그립니다. 그림은 전부 TypeScript 로 만든 SVG + SMIL 애니메이션이라 이미지 파일이 없습니다.
  • Claude Code 2.1.287 이상이 필요하고, 모드는 얼리 액세스라 API 가 바뀔 수 있습니다. 움직이는 그림은 데스크톱 앱에서만 보이고 터미널에서는 정지된 글자 그림으로 나옵니다.
