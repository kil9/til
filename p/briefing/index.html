02Emacs, 50주년을 맞다

Emacs 가 1976년 MIT AI 연구소에서 나온 지 50년이 됐습니다. 처음부터 새 편집기를 만들려던 것은 아니었습니다. 사람마다 제각각 고친 Control-R 명령을 하나로 맞춰서 서로 도울 수 있게 하려던 것이 출발점이었습니다.

  • TECO 의 화면 편집 확장인 Control-R 에서 모든 키가 각자 매크로를 실행하게 바꾼 것이 맞춤화의 시작이었습니다. 이후 Guy Steele, David Moon, Stallman 이 Meta 키를 써서 명령을 표준화했습니다.
  • Stallman 은 개선 사항을 공동체에 돌려준다는 조건으로 누구에게나 Emacs 를 나눠 줬습니다. Honeywell 판과 Gosling 판이 상용으로 팔리자 GNU Project 를 시작했습니다.
  • Apple 은 2001년 Mac OS X 에 GNU Emacs 를 넣었다가 2019년에 뺐습니다. 그래도 mg 편집기와 OS 단축키에 흔적이 남아 있습니다.

05winevdm - 64비트 Windows에서 16비트 Windows 프로그램 실행하기

winevdm 은 Windows 1.x 부터 3.1 까지의 16비트 프로그램을 64비트 Windows 에서 실행하는 에뮬레이터입니다. CPU 에뮬레이터에 Wine 의 Win16→Win32 변환 코드를 붙였고, 16비트 핸들과 네이티브 핸들 사이의 변환도 처리합니다.

  • 실행 파일을 otvdm.exe 에 끌어 놓으면 실행되고, 설치한 뒤에는 Win16 실행 파일을 바로 열 수 있습니다.
  • 옛 프로그램이 %WINDIR% 에 ini 파일을 쓰려고 하면, 요즘 Windows 에서는 막히는 경로라 다른 곳으로 돌려서 저장합니다.
  • HN 댓글에서는 Microsoft 가 왜 이걸 직접 만들지 않았느냐는 물음이 나왔습니다. 64비트 핸들은 유효 비트가 32비트라 16비트로 잘라 넘길 수 없다는 답이 달렸습니다.

06kern - AI 생성 코드를 매번 새 컨테이너에서 실행하는 경량 루트리스 런타임

kern 은 AI 가 만든 코드나 에이전트의 도구 호출을 호스트에서 바로 돌리지 않고, 호출할 때마다 새 컨테이너에서 실행하는 Linux 런타임입니다. 데몬도 소켓도 없는 정적 바이너리 하나이고 root 권한 없이 돌아갑니다.

  • /bin/true 를 실행하고 끝내는 기준으로 docker run --rm 보다 단건은 약 80배, 200개 동시 실행은 약 130배 빠릅니다. rootless runc 와 비교하면 약 3.6배입니다.
  • Python/Node SDK 와 MCP 서버를 제공합니다. 기본값으로 네트워크와 호스트 디렉터리 접근을 막고, 타임아웃·메모리 초과·시작 실패를 구분된 결과로 돌려줍니다.
  • 호스트 커널을 공유하는 격리라서, 여러 테넌트가 외부의 적대적인 코드를 돌리는 용도로는 권하지 않습니다.
